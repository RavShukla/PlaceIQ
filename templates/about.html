My Approach

A model isn't finished when model.fit() runs.

For me, machine learning becomes genuinely interesting when a trained model leaves the notebook and starts solving a problem through a usable application.

That's why I focus on the complete process: understanding the problem, exploring the data, selecting useful features, experimenting with models, evaluating performance and then integrating the final model into software.

I'm continuously expanding my understanding of machine learning, AI and software engineering while building projects that force those skills to work together.

Featured Project

Meet PlaceIQ.

An end-to-end machine learning project built to turn student profile data into placement insights.

MACHINE LEARNING PROJECT

Student Placement Prediction System.

PlaceIQ analyzes academic performance, practical experience, aptitude, soft skills and placement preparation to estimate whether a student is likely to be placed.

The project covers the complete data science workflow: data understanding, exploratory analysis, preprocessing, model training, evaluation, serialization, Flask backend integration and a responsive frontend.
